# Design Doc: Morning Mindset & Meditation Journal (아침 명상 & 마인드셋 다이어리)

**Date:** 2026-10-27  
**Status:** Approved by Founder  
**Stack:** React 19 + Vite + Tailwind CSS + Lucide React + LocalStorage / IndexedDB

---

## 1. Executive Summary & Problem Framing
- **Core Value Proposition:** 매일 아침 맞춤형 명상/집중 음악(유튜브 연동)과 동기부여/마인드셋 글귀를 제공받고, 감상 후 자신의 다짐과 감정을 즉시 기록하여 날짜별로 누적·검색·회고할 수 있는 올인원 모닝 루틴 웹 애플리케이션.
- **Target Audience:** 매일 아침을 의도적이고 차분하며 활기차게 시작하고 싶어하는 직장인, 학생, 크리에이터 및 자기계발 실천가.
- **Completeness Target:** 10/10 (Boil the lake) — 모든 엣지 케이스 처리(오프라인 대응, 데이터 내보내기/가져오기, 검색 필터링, 감정 통계, 반응형 모바일/데스크톱 UI, 다양한 테마 및 음악 카테고리 큐레이션).

---

## 2. Key Features & Specifications

### 2.1 아침 명상 & 집중 음악 (YouTube Integration)
- 엄선된 명상 및 활력 음악 큐레이션 (차분한 싱잉볼/자연의 소리, 딥 포커스 피아노, 상쾌한 로파이/재즈, 에너지 넘치는 모닝 어쿠스틱).
- 인앱 유튜브 플레이어 (IFrame 임베드) & 직접 유튜브에서 보기 링크.
- 사용자가 원하는 유튜브 URL을 직접 추가하여 나만의 모닝 플레이리스트로 저장하는 커스텀 기능.

### 2.2 오늘의 마인드셋 글귀 & 영감 메시지
- 활기찬 하루의 시작, 긍정 확언(Affirmation), 철학적 명언, 도전과 회복탄력성 메시지 큐레이션.
- 매일 자동으로 오늘의 글귀 배정 + 언제든 새로운 글귀를 뽑아볼 수 있는 "오늘의 영감 새로고침" 기능.
- 마음에 드는 글귀 북마크 및 저널 본문에 인용(Quote)으로 바로 삽입 기능.

### 2.3 마인드셋 저널링 (마음가짐 기록)
- 오늘 나의 감정 상태(Mood) 선택 (평온함, 활기참, 감사함, 집중, 결의, 휴식 등 귀여운 이모지/배지).
- "오늘의 마음가짐과 목표", "감사한 일 3가지", "나에게 건네는 한마디" 구조화된 프롬프트 지원.
- 자유 텍스트 작성 및 자동 저장(Auto-save draft) 기능.

### 2.4 날짜별 검색, 캘린더 조회 및 아카이브
- **인터랙티브 캘린더:** 기록이 있는 날짜에 감정 인디케이터 표시, 날짜 클릭 시 해당 날의 음악, 글귀, 일기 즉시 조회.
- **강력한 검색 및 필터링:** 날짜 범위, 감정 무드 태그, 키워드 검색 지원.
- **연속 기록 스트릭(Streak) 및 통계:** 며칠 연속 아침 루틴을 달성했는지, 가장 많이 느낀 감정 통계 차트.
- **데이터 백업 및 복원:** JSON 내보내기/가져오기(Export/Import) 지원으로 데이터 손실 원천 방지.

## 3. Architecture & Data Flow

```
[ Local Storage / IndexedDB ]
             │ (Data Sync & Persistence)
             ▼
[ React Custom Hooks: useJournal, useMorningContent, useStreak ]
             │
   ┌─────────┴─────────┬───────────────────┐
   ▼                   ▼                   ▼
[ TodayView ]    [ CalendarView ]    [ ArchiveSearchView ]
 • YouTube Player  • Month Grid        • Keyword Filter
 • Daily Quote     • Mood Badges       • Mood Filter
 • Journal Form    • Day Inspector     • JSON Export/Import
```

---

## 4. Implementation Steps
1. Vite + React + Tailwind CSS 스캐폴딩 설정.
2. Lucide Icons 및 UI 컴포넌트 라이브러리 구성.
3. 큐레이션 데이터셋 구축 (검증된 명상/모닝 음악 유튜브 링크 20+개, 감동적인 마인드셋 글귀 30+개).
4. LocalStorage 데이터 레이어 및 CRUD 구현.
5. 반응형 UI (모바일 최적화, 다크/라이트 모드 지원, 세련된 글래스모피즘 디자인).
6. 엣지 케이스 및 사용자 편의 기능 (오프라인 폴백, 데이터 백업/복원).
7. 빌드 검증 및 프로덕션 프리뷰 테스트.
