# ☀️ Morning Mindset (아침 명상 & 마인드셋 다이어리)

매일 아침 맞춤형 명상/집중 음악(유튜브 연동)과 새로운 활력을 주는 마인드셋 글귀를 제공받고, 감상 후 오늘의 다짐과 감정을 즉시 기록하여 날짜별로 영구 저장·검색·회고할 수 있는 모닝 루틴 웹 애플리케이션입니다.

---

## 🌟 주요 기능 (Key Features)

1. **아침 명상 & 집중 음악 (YouTube Integration)**
   - 528Hz 치유의 주파수 싱잉볼, 평온한 피아노, 모닝 어쿠스틱 기타, 자연의 숲소리, 로파이 비트 등 엄선된 플레이리스트.
   - 인앱 플레이어 임베드 및 유튜브 바로가기 지원.
   - **나만의 유튜브 링크 추가:** 평소 좋아하는 유튜브 음악 URL을 직접 등록하여 나만의 모닝 플레이리스트 구성 가능.

2. **오늘을 여는 마인드셋 & 영감 (Curated Inspiring Quotes)**
   - 마르쿠스 아우렐리우스, 세네카, 틱낫한, 루미, 생텍쥐페리 등의 명언과 성찰 질문 제공.
   - '새로운 영감 보기' 버튼을 통한 글귀 새로고침.
   - '이 글귀를 내 다이어리에 인용하기' 원클릭 지원.

3. **마인드셋 저널링 (Morning Journal)**
   - 오늘 아침 감정(Mood) 선택 (🌿 평온함, ☀️ 활기참, 🙏 감사함, 🎯 집중, 🔥 결의 등).
   - 3가지 구조화된 가이드:
     1. 오늘 하루 나의 다짐과 마음가짐
     2. 아침 감사 3가지 (Three Gratitudes)
     3. 자유 성찰 및 명상 메모
   - 축하 컨페티 효과 및 자동 로컬 영구 저장 (`localStorage`).

4. **달력(캘린더) 조회 & 날짜별 상세 인스펙터**
   - 월별 캘린더를 통해 기록이 있는 날짜에 감정 이모지와 인디케이터 표시.
   - 특정 날짜 클릭 시 해당 일의 마음가짐, 감사 목록, 들었던 음악 및 글귀 즉시 조회 및 수정/삭제.

5. **강력한 기록 검색 & 아카이브**
   - 키워드 실시간 검색 (다짐 내용, 감사한 일, 명언, 날짜 등).
   - 감정별 필터링 (All, 평온함, 활기참 등) 및 최신순/과거순 정렬.

6. **연속 기록 스트릭(Streak) & 통계**
   - 며칠 연속 아침 루틴을 달성했는지 실시간 스트릭 카운팅.
   - 총 누적 세션 및 감정 분포 시각화 바 차트.

7. **데이터 안전 백업 및 복원 (Export / Import)**
   - JSON 파일 원클릭 다운로드로 언제든 백업 가능.
   - 기기 변경 시 백업 파일 업로드로 즉시 복원.

## 🚀 실행 방법 (Getting Started)

### 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:3000` 접속

### 프로덕션 빌드
```bash
npm run build
```
`dist/` 폴더에 최적화된 정적 웹 에셋 생성

---

## 🛠 기술 스택
- **Frontend:** React 18, Vite 6, Tailwind CSS v3
- **Icons:** Lucide React
- **Celebration:** Canvas Confetti
- **Storage:** Browser LocalStorage (오프라인 지원, 완전 독립 실행)
